# Getting help

Use [GitHub issues](https://github.com/MasterSon-git/vic3-kmpmp/issues) for
reproducible bugs, feature proposals, compatibility failures and corrections to
credits or licensing. Search first and add evidence to an existing report when
it describes the same problem.

Include the exact game version/checksum, KMPMP commit or Workshop update, variant,
DLC list, playset/load order and reproduction steps. A small save immediately
before the problem and relevant log excerpts help more than a screenshot alone.
See [Testing](docs/TESTING.md) for details. Remove personal information from logs
and saves before sharing them.

This is community maintenance; response times and support for arbitrary mod
combinations are not guaranteed. Do not post passwords, Steam credentials or
private server details in an issue. This project does not currently publish a
private security-reporting contact; do not post exploit instructions or secrets
publicly. Use GitHub's private vulnerability reporting option if it is offered
on the repository's Security page.
